# Wireframe

## Layout

- Single page app
- Top: Create task form
- Bottom: Task list

## Task List Item

Each task shows:

- Title
- Description
- Status badge

Buttons:
- Edit
- Delete
- Change status

## Forms

### Create / Edit Task Form
- title input
- description input
- submit button

## Behavior

- After create → refresh list
- After update → update UI immediately
- After delete → remove from list
